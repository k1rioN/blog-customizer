# Blog Customizer

Страница статьи с боковой панелью настроек оформления. Проектная работа Яндекс
Практикума (курс «Фронтенд-разработчик. Расширенный»).

## Что умеет

- Панель настроек открывается и закрывается кнопкой-стрелкой, а также
  закрывается кликом вне панели.
- Настройки: шрифт, размер шрифта, цвет шрифта, цвет фона, ширина контента.
- Изменения применяются к статье только по кнопке «Применить», кнопка
  «Сбросить» возвращает настройки по умолчанию.
- Настройки передаются в статью через CSS-переменные (`--font-family`,
  `--font-size`, `--font-color`, `--bg-color`, `--container-width`), поэтому
  оформление меняется без перерисовки разметки.
- UI-компоненты — выпадающий список, радиогруппа, кнопки, разделитель —
  описаны в Storybook. Выпадающий список закрывается по клику вне него и
  управляется с клавиатуры.

## Стек

React 18, TypeScript, SCSS-модули, Webpack, Storybook, ESLint, Stylelint,
Prettier, Husky.

## Запуск

```bash
npm install
npm start              # dev-сервер
npm run storybook      # Storybook на http://localhost:6006
npm run build          # production-сборка
```

Проверки кода: `npm run lint`, `npm run stylelint`, `npm run format`.
